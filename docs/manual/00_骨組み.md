# 初心者マニュアルの骨組み（2026-11-12 ルナ）

中身を詰める前に、ぶれない軸だけ決める。章立ては見本シーンを作ってから確定する。過去のChatGPT（リナ）とのログは草案扱い。

## 誰に

- Blenderを一度も触ったことがない人。3DCG・GIS・プログラミングの知識なし。
- 松井さんの要望：「キャプチャを入れて『ここをこう』と、超超初心者でも分かるように」。

## 完成の定義

マニュアルと配布物だけで、本人が一人で次の三つまで行ける。

1. **見る**：配布した見本（計算済みの津波シーン）を開いて再生し、水が街でどう動くかを観察できる。
2. **作る**：PLATEAU Bridgeアドオンで自分の選んだ街を出し、「軽量化」して、水を流せる。
3. **変える**：水の来る方向や量を変えて計算し直し、違いを動画で保存できる。

1だけでも教材として成り立つように作る（2・3で詰まっても成功体験が残る）。

## 見本シーンに求めること

- 再生するだけで、流体の効き方が分かる：水が建物にぶつかる／回り込む／通りに沿って流れ込む／建物の陰は水が遅い。
- 計算済みキャッシュを同梱し、開いてすぐ再生できる。
- 性能の基準は事業所PC（K3 Pro：i7-12650H、内蔵GPU）。そこで再計算できる設定を「編集用」として別に用意する。
- 防災の予測ではなく、物理演算による可視化の体験教材だと明記する。

## 書き方の約束

- 1操作ごとに：やること → 実画面キャプチャ（赤枠・番号）→ 成功した時の画面 → うまくいかない時。
- 「ここ」「それ」ではなく、画面上の名前と位置で書く。
- キャプチャは手順と画面が固まってから撮る（Bridgeの画面が変わるたびに撮り直さない）。

## 決まっていないこと

- 章立て、ページ数、形式（PDFかWebか）。
- 対象Blenderのバージョン固定（今は5.2.3 LTSで検証）。
