## この章でやること

PLATEAU Bridge で作った街に、上から水の塊を落として、水が建物にぶつかって流れていく様子を見ます。

かかる時間：約15分（水の計算は、ふつうのPCで1〜数分）

道は3つあります。好きなものを選んでください。

| 道 | やること | おすすめの人 |
|---|---|---|
| A. 読み込むだけ | 配布データ「水の塊_400m.blend」を街に追加する | まず動くのを見たい人 |
| B. スクリプトを1回押す | 配布スクリプト「水を落とす.py」を実行する | 街の広さが400m以外の人 |
| C. 自分で作る | 立方体2つに水の設定をする | 仕組みを知りたい人（この章のメイン） |

> この章で作る水は、物理演算で水の動きを体験するためのものです。実際の津波や浸水の予測ではありません。

---

## 準備：街が「水の障害物」になっているか確かめる

PLATEAU Bridge で作った街は、最初から水の障害物（エフェクター）になっています。

1. 画面右上のアウトライナーで「PLATEAU_Buildings」をクリックします。
2. 画面右側のプロパティで、青い丸の「物理演算」タブ※をクリックします。
3. 「流体」が青くなっていて、タイプが「エフェクター」なら準備OKです。

［キャプチャ：物理演算タブ、流体＝エフェクター］

**うまくいかない場合**：「流体」が押されていない時は、PLATEAU Bridge の「今回の設定をすべて見る」で「水の障害物にする」にチェックを入れて街を作り直すか、ここで「流体」を押してタイプを「エフェクター」にします。地形（GSI_Terrain）も同じです。

---

## 道A：読み込むだけ

1. 上のメニューの「ファイル」→「アペンド」※をクリックします。
2. 配布フォルダの「水の塊_400m.blend」をダブルクリックします。
3. 「Collection」フォルダをダブルクリックし、「水の塊」を選んで「アペンド」を押します。
4. 画面下のタイムラインの再生ボタン（▶）を押します。スペースキーでも再生できます。

［キャプチャ：アペンドの画面で「水の塊」を選んだところ］

**成功すると**：街の真ん中の上に置かれた水の塊が落ちて、建物の間に広がります。最初の1回は計算しながら再生するので、ゆっくり動きます。2回目からはなめらかです。

**うまくいかない場合**：水が街からはみ出す・端に寄る時は、街の広さが400mではありません。道Bを使ってください。

---

## 道B：スクリプトを1回押す

1. 画面上のタブの「Scripting」をクリックします。
2. 真ん中の大きな欄の上にある「開く」を押し、配布フォルダの「水を落とす.py」を選びます。
3. 欄の右上にある ▶（スクリプト実行）を押します。
4. 「Layout」タブに戻り、タイムラインの再生ボタンを押します。

［キャプチャ：Scripting タブ、開くボタンと実行ボタンに番号］

**成功すると**：道Aと同じように水が落ちます。街の広さに合わせて、水の範囲が自動で決まります。

**ちょっと変えてみよう**：スクリプトの上の方にある数字を書き換えて、もう一度 ▶ を押します。
- `WATER_SIZE = 0.3` を `0.5` にすると、水の塊が大きくなります。
- `RESOLUTION = 64` を `96` にすると、水の形が細かくなります（計算に時間がかかります）。

## 道C：自分で作る

水のシミュレーションには、3つの役割があります。

| 役割 | Blenderでの名前 | この章では |
|---|---|---|
| 水を計算する範囲（水槽のようなもの） | ドメイン | 街を包む大きな箱 |
| 水が出てくる所 | フロー | 街の上の小さな箱 |
| 水がぶつかる物 | エフェクター | 街（作った時に設定済み） |

### STEP 1　水槽になる箱を置く

1. 3Dビューの上で `Shift` + `A` を押し、「メッシュ」→「立方体」を選びます。
2. 右側の「オブジェクト」タブ（オレンジの四角）で、次のように入力します。
   - 位置：X `0`、Y `0`、Z `24`
   - 寸法※：X `400`、Y `400`、Z `50`（街の広さが200mなら X・Y は `200`）

［キャプチャ：寸法の欄に赤枠］

**成功すると**：街全体が大きな灰色の箱に隠れます。これで正しいです。

### STEP 2　箱をドメインにする

1. 箱を選んだまま、「物理演算」タブで「流体」を押します。
2. タイプを「ドメイン」、ドメインタイプを「液体」にします。
3. 「解像度分割数」※を `64`、「時間の倍率」※を `3` にします（3倍の早回し。街は大きいので、実際の速さだと水がほとんど進まないうちに終わってしまいます）。
4. 「メッシュ」の欄のチェックを入れます（水の表面がなめらかになります）。
5. 「キャッシュ」の欄で、タイプを「リプレイ」※、終了を `96` にします。
6. 箱が邪魔なので、「オブジェクト」タブの「ビューポート表示」で、表示方法を「ワイヤーフレーム」にします。

［キャプチャ：ドメイン設定の各欄に①〜⑤］

### STEP 3　水の塊を置く

1. `Shift` + `A` →「メッシュ」→「立方体」を選びます。
2. 位置：X `0`、Y `0`、Z `32.5`／寸法：X `120`、Y `120`、Z `15`（街の広さが200mなら X・Y は `60`）
3. 「物理演算」タブで「流体」を押し、タイプを「フロー」、フロータイプを「液体」、フローの動作を「ジオメトリ」にします。

［キャプチャ：フロー設定］

**ポイント**：「ジオメトリ」は、最初に箱の形の水が1回だけ現れる設定です。「インフロー」にすると、水が出続けます（あとで試してみましょう）。

### STEP 4　再生する

1. タイムラインの終了を `96` にします。
2. 先頭のフレームに戻り（`Shift` + `←`）、再生ボタンを押します。

**成功すると**：水の塊が落ちて、建物にぶつかり、通りに沿って広がります。

**うまくいかない場合**
- 水が出ない：再生位置が1フレーム目から始まっているか、フローの箱がドメインの箱の中にあるかを確かめます。
- 水が建物をすり抜ける：建物の「流体」がエフェクターになっているか確かめます（準備の項）。
- とても遅い：解像度分割数を `48` に下げます。

## もっと試してみよう

| 変える所 | どう変わるか |
|---|---|
| 解像度分割数 64 → 128 | 水の形が細かくなる。計算は約5倍の時間 |
| フローの動作 ジオメトリ → インフロー | 水が出続けて、街が水で満ちていく |
| フローの「初速度」をオンにして X に数字 | 水が横向きに飛び出す（見本「水の激突」はこれで作っています） |
| 水の箱を2つにして、向かい合わせに初速度 | 水どうしがぶつかって、しぶきが上がる |
| ドメインの「時間の倍率」 3 → 1 | 実際の速さになる。水がゆっくりに見えるのは、街が大きいから |
| 水の箱の位置を海側へ | 海から陸へ流れ込む様子になる |

## メモ（制作用・本文には載せない）

- 計測（K12、窓なし、山下公園400m）：スクリプトの既定（解像度64・96フレーム・3倍）で再生しながらの計算 5.6秒。K3 Proでは未計測。
- 見本は「じわっとしたリアルな津波」ではなく「液体の機能を体感しやすい派手なシーン」にする（2026-11-12 マスター判断）。山下公園の津波案（波8m・じわっと浸水）は不採用。
- 見本「水の激突」：渋谷スクランブル交差点 200m（`35.6595, 139.7005`）。西端と北端に水の壁（各 28×196×高さ25m、地面+1m）を置き、初速 20m/s で交差点へ向けてぶつける。ドメイン 200×200×60m、解像度128、120フレーム（5秒）、時間の倍率2。K12で計算158秒、描画（EEVEE、1280×720）171秒。再生用キャッシュ（mesh）約490MB、フォルダ合計501MB（`_runs/manual/見本_激突_渋谷/`）。
- 演出：Sky Texture（MULTIPLE_SCATTERING、太陽高度7°）、太陽 7W・暖色、反対側から青い補助光、AgX、水は Base Color (0.02,0.16,0.22)・Roughness 0.04・Transmission 0.55。カメラは南東上空から交差点へ寄り、激突の後に南へ回り込む（水面より上を通す。低いと水の中に入る）。
- 試した時の目安：解像度96・壁15m・15m/sは計算29秒で、しぶきが小さい。
- 道Cの数値は、配布スクリプトの既定と同じ結果になるように揃えてある。
