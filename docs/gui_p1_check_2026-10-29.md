## 見つかった問題（未修正）

1. **キャンセルが失敗として表示される。** タイトル「処理失敗」、エラーアイコン、本文先頭に `CancelledError:`、状態行「処理に失敗しました」。利用者が止めた時は中止として案内したい。
2. **完了後の「Blenderで街を開く」が目立たない。** 主CTAなのに右端の小さなボタンで、右枠が窓端で切れる。大きいのは「3Dの街を作る」のまま。
3. **初期サイズ `900x780`（枠込み 916×819）が 1366×768 の作業領域（高さ約720）を超える。** 最小サイズでは収まるので、画面高に合わせて初期サイズを縮めればよい。
4. 小さな点: フォーカス枠が淡い／ラジオボタンが1個ずつ Tab で止まる／ログ保存ダイアログの初期フォルダが `Documents` 直下。

## 修正（同日、`auto_gui.py`）

1. 中止は `CancelledError` を `'cancelled'` として分け、「中止しました」の案内ダイアログと状態行（`CANCELLED_MESSAGE`）にした。Blender自己診断の中止も同じ扱い。
2. 「Blenderで街を開く」はボタン行の下に全幅・太字（`Primary.TButton`）で出し、完了ダイアログを閉じるとフォーカスが移る。
3. 初期サイズは `initial_geometry()` で画面に合わせて縮める（1366×768 → `900x638`、最小 580）。
4. ラジオボタンはグループで Tab 1回、矢印キーで選択（`radio_group` / `step_radio`）。ログ保存と保存先変更のダイアログは、保存先 `.blend` のフォルダ（無ければ存在する親）から開く（`existing_dir`）。
   - フォーカス枠の淡さは未対応。ttk の vista テーマは Windows 標準の点線枠を描き、色や太さを変えられないため。

テスト 119件成功（追加4件）。`dist-next` で再ビルド→self-check合格→`dist` へ昇格（旧 `dist` は `dist-old\dist-2026-10-28`）。配布先 `app` を入れ替え（旧版は `app-prev-2026-10-28`、旧ZIPは `PLATEAU-Blender-Bridge-prev-2026-10-28.zip`）。1,085ファイルのハッシュ一致、配布先 self-check 合格（`verification\self-check-2026-10-29-p1fix.json`）。
