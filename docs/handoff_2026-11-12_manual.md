松井さん（リスタル）向けに、Blender未経験者が「実在の街を出して、水を流して、液体の動きを体感する」までを一人で進められるマニュアルを完成させる。

- 防災の予測ではなく、物理演算で水の動きを体験する教材だと明記する。

## 決まったこと（マスター判断、2026-11-12）

- アドオンは変換に絞る。水の設定（ドメイン・フロー）はアドオンに入れず、マニュアル・スクリプト・配布データで扱う。
- 見本は「じわっとしたリアルな津波」ではなく「液体機能を体感しやすい派手なシーン」。山下公園の津波案は不採用。
- 軽い版は、ローポリの街にデフォルメの水で「軽い版だ」と見て分かるようにする。
- K3 Pro（事業所PC、i7-12650H・内蔵GPU）が性能の基準。リプレイは解像度24〜32でも重い。先にベイクすれば48でも滑らか。→ 教材の既定は「解像度48・キャッシュ『すべて』で先にベイク」。リプレイは使わせない。
- 日本語画面の表記（Blender 5.2.2で確認済み）：「分割の解像度」「タイムスケール」「リプレイ」「モジュール」「すべて」。原稿の※印は未照合。

## 残っている仕事

1. **章立てを決める**：インストール → 基本操作 → 見本を再生（見る）→ アドオンで街を作る → 水を流す（作る）→ 条件を変える・動画で保存（変える）が軸。付録（用語・困った時・データの出典と利用条件）。
2. **各章の本文**：1操作ごとに「やること → キャプチャ（赤枠・番号）→ 成功すると → うまくいかない場合」。
   - アドオンのインストール手順の土台：`blender_addon/full_trial_request_draft.md`（ZIPをドラッグ＆ドロップ、オンラインアクセス許可、N キー →「PLATEAU」タブ）。
   - 動画で保存する章は未着手（Blender 5系は出力の `media_type` を動画にしてから形式を選ぶ。画面上の手順を確かめる）。
3. **キャプチャ撮影**：窓ありの Blender を Blender MCP（`mcp__blender__*`、`look` で画面確認）で操作して撮る。手順が固まってから撮る。日本語UIで撮る。
4. **K3 Proでの確認**（マスターに依頼）：軽い版の見本が滑らかに再生できるか。本番版は重い可能性あり（1フレームの水が約22万頂点）。結果でマニュアルの「このPCならこっち」を書き分ける。
5. **未確認の動作**：`水を落とす.py` を窓ありで実行した時の裏ベイク（`bake_all("INVOKE_DEFAULT")`）。窓なしでは確認済み。
6. **出典表記**：PLATEAU（国土交通省）と地理院タイルの出典・利用条件を付録へ。アドオンのパネルに出している文言（`catalog.ATTRIBUTION`）と揃える。
7. **形式**：PDFかWebか未定。マスターに聞く。
8. **配布の形**：見本フォルダ（Git 外）とアドオン zip、assets をどうまとめて渡すか。
