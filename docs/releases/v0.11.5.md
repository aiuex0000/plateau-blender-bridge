# PLATEAU Blender Bridge v0.11.5

作る範囲を地図で確認できるようにし、保存した街を Windows のファイルの関連付けから開けるようにしました。

## ダウンロードと起動

`PLATEAU-Blender-Bridge-v0.11.5-win-x64.zip` を展開し、`PLATEAU-Blender-Bridge.exe` を開いてください。`_internal` と `tools` は実行ファイルと同じフォルダに置いてください。

Windows 10 / 11（64ビット）、Microsoft Edge、Blender、インターネット接続が必要です。Blender は別途インストールしてください。

## この版の変更

- 完了画面の「保存した .blend を開く」は、Windows で `.blend` に関連付けたアプリで開きます。「保存したフォルダを開く」からファイルの場所も確認できます。
- 場所と広さからファイル名を提案します。同じ名前のファイルがある場合は、既存ファイルを残して連番を付けます。
- 「広さ」の「地図で範囲を確認」を開くと、指定範囲の枠と中心が国土地理院の標準地図に表示されます。地図を取得できない場合も、生成に進めます。
- PLATEAU のデータがない場合は「場所を変える」、保存先に書けないと判定した場合は「保存先を変える」から、該当する画面に戻れます。

ZIP の SHA-256 は添付の `SHA256SUMS.txt` で確認できます。同梱ソフトウェアのライセンスは `THIRD_PARTY_LICENSES.txt` と `tools/nusamai/` にあります。
