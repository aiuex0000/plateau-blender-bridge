# PLATEAU Bridge 本体の試用をお願いする文面

添付ファイルは `blender_addon/dist/plateau_bridge-0.2.1.zip` です。以下を Slack に貼って使えます。

---

松井さん、お疲れさまです。先日は会社のPCで試作を確認していただき、ありがとうございました。今度は、Blenderの中で地形・航空写真・建物をまとめて取り込める本体を、同じPCで試していただけますか。

1. Blenderを開き、添付のZIPを解凍せずにBlenderの画面へドラッグ＆ドロップして、インストールします。うまくいかない場合は「編集 → プリファレンス → エクステンションを入手」の右上のメニューから「ディスクからインストール」を選び、同じZIPを指定してください。
2. オンラインアクセスが無効と出たら、「編集 → プリファレンス → システム → ネットワーク」で「オンラインアクセスを許可」をオンにします。地形や建物のデータを取得するために使います。
3. 新規シーンの3Dビューにカーソルを置き、`N` キーでサイドバーを開いて「PLATEAU」タブを選びます。「どこの街を作りますか？」の一覧で「東京タワー」を選び、広さを「200 m」にして「3Dの街を作る」を押してください。
4. 「街ができました！」と出たら、地形と建物が表示されたかを見て、「結果をコピー」の内容をこのSlackに貼ってください。本体とBlenderのバージョンも一緒にコピーされます。

途中で止まった場合は、どの操作で止まったかと、画面に出たメッセージを教えていただければ助かります。よろしくお願いします。
