# 試作アドオンのお願い文（案）

添付: `blender_addon/dist/plateau_bridge_trial-0.0.1.zip`
送信はマスターが行う。以下は Slack へそのまま貼れる文面の案。

---

松井さん、お疲れさまです。

PLATEAU のツールを、exe ではなく Blender のアドオンとして作り直しています。会社のPCで止められないかを先に確かめたく、小さな試作を一度だけ試していただけますか。5分ほどで終わります。

**入れ方**

1. 添付の zip を解凍せずに、Blender の画面へドラッグ＆ドロップします。確認が出たら、そのままインストールしてください。
   - うまくいかない時は「編集 > プリファレンス > エクステンションを入手」の右上にある「∨」から「ディスクからインストール」を選び、zip を指定します。
2. 「編集 > プリファレンス > システム > ネットワーク」の「オンラインアクセスを許可」にチェックを入れます（地図の画像を1枚取りに行くためです）。

**試すこと**

1. 3Dビューの上でキーボードの N を押し、右に出る帯の「PLATEAU」タブを開きます。
2. 「地理院タイルを1枚取り込む」を押します。東京駅あたりの航空写真が貼られた四角い板が出れば成功です。
3. 板の下に出る「結果をコピー」を押し、この Slack へ貼り付けて送ってください。Blender の版もそこに入っています。

**教えてほしいこと**

- zip は入りましたか。
- ボタンを押して、写真の板は出ましたか。
- 途中で Windows や Blender に止められた時は、その画面の写真をお願いします。どこで止まったかが分かれば十分です。

うまくいかなくても、それが分かること自体が助かります。よろしくお願いします。
